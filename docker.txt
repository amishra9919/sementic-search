3. check for container : 
    docker ps     //shows running container

4. run ubuntu inside docker: 
    docker run -it ubuntu   
    //here 'ubuntu' is terminal and '-it' is interactive terminal 
    //so if we exec only docker run ubuntu .. it returns nothing it enters to the container and exit immedieately 

5. create docker container with its name 
    docker run -it --name arpit ubuntu      //here container name is arpit and image name is ubuntu

6. docker run vs start:
    //docker run is executed while creating new container
    //docker start is executed to run the existing container: 
    docker start -ai arpit

    //docker call this detatch mode -d

11. docker port mapping 
    -p machine_port:container_port
    //Port mapping, -p HOST_PORT:CONTAINER_PORT, Your PostgreSQL server is listening on port 5432 But machine will accesses it through 5433
